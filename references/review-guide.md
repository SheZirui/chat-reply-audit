# 长间隔上下文审阅

需要逐步命令、离线表单填写、在线 Codex 提示、API 密钥输入或本地模型配置时，先看[完整操作流程](../docs/WALKTHROUGH.md)。本页定义分类规则与 JSON 字段。

## 先回答三个不同问题

1. **测到了什么？** 第一条或最后一条到下一方首次发言的间隔。
2. **是否留下待回应事项？** 新提问、请求、明显寻求关心的分享，还是已回答、确认、晚安或话题收尾。
3. **为什么延后，是否适宜？** 对方明确说明、约定晚些再回、线下见面、可能休息等；说明只作为可见证据，不能替对方编造，也不能把没看到原因等同没原因。

没有已读信息，不能判断何时看到；当面沟通、电话、媒体内容或导出缺失可能改变结论。

## 审阅动作

先读前文，确认此刻是否刚刚结束旧问答；再读整个waiting段，找新事项起点和后续补发；最后读after，看是否引用旧问题、另聊新话题、解释原因或表达等待感受。

如果关键证据在默认窗口外，重新prepare-review，增加before/after或单条字符上限，再审阅。所有证据应进入提交的上下文包。引用ref来自实际消息，不手写不存在的时间点。

无法识别的语音、图片或转发内容可能是核心证据。这时保留不确定。不要用固定“静默几小时”的规则强行切断对话，也不要因对话里出现“好”就自动判收尾。

## 分类

| status | 适用情形 | revised_start_ref |
|---|---|---|
| retained | 上下文支持存在待回应内容，修正后仍严格超过阈值 | waiting中真实起点ref |
| restart | 旧事项结束后新开话题，修正后不超过阈值 | waiting中新话题首条ref |
| closed | 旧事项已完成，未确认还留下待答问题 | null |
| agreed_deferral | 原文明示不着急回、稍后/次日再聊等 | null |
| uncertain | 期待、分界、媒体或线下情况不足以判断 | null |
| unreviewed | 尚未审阅，不能冒充不确定或0次 | null |

`retained`不是“确定故意不回”，也不意味着此人不合理。`closed`也不是证明对方绝无期待，只是当前证据不支持把整个长间隔视为持续待答。

普通照片隔夜才被评论，可以确定有延后反馈；是否真的一直在等，还需要其余上下文。若当事人随后明确表达“之前的图片还没回应”，或回复精确对应一个未解问题，证据会更强。

下一方的首次发言可能只是晚安或另一个话题，未解决最初的问题。校准时长仍以首次发言为界，理由里必须说明“恢复聊天”与“具体事项获得答案”是否一致。不要把只复核候选后的保留数量当作整个聊天漏答率。

## 一条审阅记录

```json
{
  "event_id": "E000001",
  "status": "retained",
  "revised_start_ref": "M000001",
  "basis_refs": ["M000001", "M000002"],
  "reason": "虚构示例中的同一问题在超过阈值后得到引用回答。",
  "context_assessment": "有明确培训说明；不能推断故意不回。",
  "context_status": "explained"
}
```

记录须放进prepare-review生成的文件结构，保留analysis_id。上面的编号只是格式示例，应使用你的真实候选包ref。

模板默认 `review_source: human_review` 供人填写；如果由 Codex 或其他模型生成答案，必须改为 `model_suggestion`。`synthetic_fixture` 仅用于完全虚构的示例，不得用于真实数据。JSON 根对象结构可参考 [虚构演示](../examples/demo-reviews.json)，不要沿用其中的分析指纹与事件编号。

使用离线表单时，`review-workbench --reviews <已有结果>`可以恢复填写；预填模型建议仍保留模型来源。保存下载的 JSON 后运行 apply-review，界面的已填写数量不等于校验成功。更改片段或扩大上下文后需要重新核对受影响的判断，analysis_id 相同也不能证明已经读过新材料。

context_status仅为解释状态：`explained`明确说明，`possible_context`只有线索，`no_explanation_visible`未见说明，`not_applicable`不适用，`insufficient`不足。它不是道德评分。

原文被截断时不允许作确定性分类，扩大上下文或改为uncertain。代码校验事件编号、引用存在、起点范围与阈值；不能校验一句话在语义上是否真的支持理由，仍需人工核对。
