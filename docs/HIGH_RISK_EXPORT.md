# 数据获取风险说明

**第三方账号数据提取／解密属于高风险活动。本项目不提供其工具推荐、下载链接、安装命令、操作步骤或代操作服务。** 本页仅解释来源风险、授权边界和已经存在的敏感副本处置，不是执行这类操作的教程或安全认证。

相关入口：[数据来源与输入准备](DATA_PREPARATION.md) · [分析与复核](WALKTHROUGH.md) · [隐私边界](PRIVACY.md)

## 为什么需要提示风险

外部工具可能读取进程内存、取得数据库密钥、产生账号消息与联系人明文，并留下日志、缓存和副本。**只分析一个会话，不代表上游取数只接触了一个会话。** 一位聊天对象的同意不能覆盖其他联系人的资料。

开源、固定版本、虚拟机、独立系统用户、断网或免责声明，都不能单独证明软件安全，也不能保证完整性、零泄露或无账号风险。本项目未审计外部获取工具。使用者需核对适用规则、平台条款和授权范围；不要因本项目支持某种输入格式就认为其任何来源均被认可。

## 使用已有文件前的边界

- 仅处理已经合法取得、且有权分析的材料。先取得参与者知情同意，说明会话范围、用途、留存期限和结果给谁看；拥有自己的账号或文件不等于对方已经同意。
- 来源、授权或接触范围无法确认时停止处理，不为使用本项目而冒险获取更多数据。可以使用虚构演示或经同意的小范围手工时间戳样本，并标注局限。
- 本机统计的同意不自动包含在线模型复核。发送前说明服务与片段范围，另行确认；不接受外发则选择人工或真正本机运行的模型。
- 不关闭杀毒、不绕过安全告警、不为取数提升管理员权限。不要将密钥、原始库、进程转储、联系人列表或完整日志交给模型、在线代处理或公开 issue。
- 真实材料应限制访问，避免与其他账号、日常文件和云同步混放。隔离环境仍有边界，共享目录、剪贴板、备份和联网后的行为也可能扩大暴露；本项目不会配置或保证这些措施。

## 已有敏感副本的保管和清理

对已经存在的临时密钥、明文库、导出和报告，默认在不再需要时逐项删除，或为确需保留的最小集合设置访问限制、加密存储和期限。**只处理自己确认路径与用途的副本，不删除来源软件的原始数据或唯一官方备份**；不运行不明的一键清理，也不对整个工作目录盲目递归删除。

| 位置／产物 | 要核对什么 |
|---|---|
| 密钥、原始数据库副本、缓存、日志 | 是否仍有必要留存，是否已经复制到其他位置 |
| CSV、上下文包、离线工作台 HTML、模型建议和报告 | 都可能含私聊；A/B 标签不等于匿名，不能直接公开 |
| 浏览器下载、编辑器备份、回收站 | 是否有遗留下载或自动保存副本，避免误删无关文件 |
| 云同步、系统备份、虚拟机磁盘与快照 | 删除当前文件不等于清除历史版本或快照 |
| API 临时配置与凭据 | 不再使用时移除；已泄露的凭据需在对应服务撤销或轮换 |

**普通删除不保证不可恢复。** SSD、文件系统、备份和云端历史可能保留副本，不能承诺彻底擦除，也不能收回已经发送给外部服务或他人的内容。不要无限期留存整账号明文和密钥。

## 怀疑已经泄露时

停止处理，隔离相关环境，避免继续联网或同步；不要把可疑材料换到另一台日常电脑重试。撤销已确认泄露的服务凭据，核对异常访问，必要时寻求可信安全支持并告知受影响者。删除副本、退出来源账号或修改密码都不能证明外发内容已收回或数据库密钥必然轮换。

这些是风险提示与材料处置原则，不是自动防护机制。本项目不会替使用者取得同意、验证来源、审计外部软件、设置系统隔离或清除文件。
