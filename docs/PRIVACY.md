# 数据和隐私边界

没有输入文件时先读[数据准备](DATA_PREPARATION.md)；操作步骤见[完整流程](WALKTHROUGH.md)。本页描述数据边界，不替代完整教程。

**第三方提取／解密属于高风险操作，本项目不提供其操作指引。** 来源风险、敏感副本处置与疑似泄露提醒见[数据获取风险说明](HIGH_RISK_EXPORT.md)。先取得聊天参与者知情同意；在线复核的服务和片段范围需要另行确认。一个对象的同意不覆盖同账号其他联系人的数据。隔离、断网、来源核查和文件删除都各有局限，不能据此保证零泄露。

## 运行方式与数据流

| 方式 | 本机读取 | 写入结果 | 外部发送 |
|---|---|---|---|
| analyze | 用户指定导出文件 | 元数据、时间及汇总；不输出正文或原始姓名 | 无 |
| review-workbench | 所选候选包与可选审阅结果 | 内嵌正文的离线 HTML，浏览器下载的结果 JSON | 页面无网络调用；浏览器扩展、同步与本机软件不由本项目控制 |
| prepare-review + 人工/Skill审阅 | 指定文件与候选 | 私密上下文、原文ref及审阅报告 | 脚本本身不发送；如果把片段交给在线Codex/其他模型，片段会进入该服务 |
| review-api | 所选候选包 | 模型建议及校验结果 | 显式发送候选正文、时间、类型及A/B标签到用户选择的服务 |

从数据库“导出为本地文件”，与把内容交给在线模型，是不同动作。不要将整个过程宣传为绝不离开本机。

外部导出工具另有自己的网络行为、权限、密钥文件、明文库与日志。本仓库不推荐特定工具、不提供操作教程，也未审计其安全。即使只导出单个会话，上游也可能先解密整账号；不能把分析项目的最小化承诺套用到导出器。

## 最小化与授权

- 只处理你有权访问、分析的单个双人会话。公共仓库不应包含任何实际参与者的消息或资料。
- 首先只做元数据统计，需要复核时再提取候选上下文。A/B替换发送方标识，不会自动清除正文里的姓名、联系方式、位置或其他身份线索；发送前自己查看片段。
- API调用需要明确的服务与内容范围；环境中存在密钥不是发送授权。`--dry-run`不联网；`--send-content`才允许程序发送。
- 图片、语音、视频不上传识别，链接不会自动访问。原始导出XML可能包含媒体参数或凭据，请不要当作可读正文导入。
- API凭据从环境变量读取，不通过命令行参数接收，不写入报告。`.env.example`只是配置说明，程序不会自动加载`.env`。

## API适配边界

只实现基本Chat Completions形状：模型名、system/user消息、可选JSON模式及输出token上限。不同服务可能不兼容，可能拒绝某些参数，或有不同的数据保留、费用及地区政策，需要使用者核实。

传输要求HTTPS，回环本地HTTP需要明确开关。拒绝自动重定向。超时、返回体大小、每个候选字符数和重试次数都有上限。失败不会自动换服务，也不会把完整API响应或认证信息打印到错误日志。

大模型可能被聊天中的指令误导、误解讽刺、猜测媒体、误判结束。系统提示将对话当作不可信证据；程序再校验引用和起点，但这不构成对模型判断正确性的保证。建议始终保留人工复核。

## 本地文件

`private-input/`与`private-output/`默认忽略。它们仍可能处于云盘、系统备份或编辑器索引覆盖范围内，项目不更改你的系统设置，也不保证这些目录不被其他软件同步。

完整教程优先把真实文件放到仓库外的专用目录。上层目录和其他仓库并不受本项目 .gitignore 保护。目录切换与提示词也不限制 Agent 实际读权限；若要求不让在线模型读正文，应自己运行本机程序，并使用实际的文件权限或隔离环境。程序不打印正文，与 Agent 另行打开原始文件，是两条不同的数据路径。

复核结果可能含私聊摘录，不能因为叫“报告”就公开。即使元数据也可能暴露生活作息。分享时优先使用仓库自带的虚构演示，或另行制作经相关参与者同意的素材。

## 发布

发布副本由精确白名单生成，不包含运行目录或真实输入。扫描只发现特定模式，并不理解全部身份线索；不能保证绝对匿名，也不审计Git历史。先人工审查，再决定是否上传。工具不含任何自动上传功能。
